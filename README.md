# Defect Escape Analyzer

## Project Overview

The Defect Escape Analyzer is a lightweight Engineering Quality prototype
designed to analyze escaped defects against software requirements and
existing test cases.

The objective is to identify what testing may have missed, determine the
likely prevention gap, and recommend additional tests or process
improvements.

## Challenge

IGS Fresher Hackathon - Challenge #14

**Defect Escape Analyzer**

## Current SDLC Stage

Planning

## Objective

Build a tool that compares escaped defects against requirements and
existing test cases to identify missed or weak testing coverage.

## Expected Outputs

1. Mapping of escaped defects to missed requirements or weak test coverage.
2. A prevention-gap category for each defect.
3. Recommended new tests or process improvements.
